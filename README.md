# Simple Family Games Website

Public website for **Simple Family Games**, a Lew Labs Apps project.

Production domain: https://simplefamilygames.com

## Site contents

- Responsive marketing homepage with all 22 games
- Current app artwork plus Favorites, Recent, and Surprise Me highlights
- Searchable and filterable game collection
- Neon Energy and Candy Pop theme switcher
- Support and privacy pages
- Custom 404 page and web manifest

The mobile app source remains in a separate private repository. This repository contains only the public website and optimized copies of approved public-facing artwork.
